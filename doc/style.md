# ZeroSkrap Website — Style Guide

## Design Philosophy

The ZeroSkrap website should feel like a **premium local business website**, inspired by the clarity and friendliness of **ScrapUncle**, but with a stronger industrial-recycling identity.

The design must communicate:

* Trust
* Professionalism
* Clean operations
* Accurate weighing
* Instant payment
* Modern recycling
* Mauritius-first identity

This is **not** a startup SaaS landing page, **not** a dark industrial junkyard website, and **not** a generic AI-generated template.

Think:

> **“A well-funded modern recycling company with excellent operations and excellent design.”**

---

# Overall Visual Direction

Use a **light, spacious, minimal interface** with soft green branding, rounded components, subtle shadows, and strong typography.

The website should immediately feel:

* Clean
* Friendly
* Efficient
* Trustworthy
* Easy to use on mobile

---

# Typography

## Primary Font

**Poppins**

Use Google Fonts.

Weights:

* 400
* 500
* 600
* 700

Do not use multiple display fonts.

Everything should be built around Poppins.

## Heading Style

* Large
* Bold
* Clean
* Minimal
* High readability

Examples:

Hero:

* 64–72px desktop
* 40–48px tablet
* 32–38px mobile

Section headings:

* 36–44px desktop
* 28–34px mobile

Body text:

* 16–18px
* 1.6 line height

# Contrast Rules

Maintain strong readability.

Never place gray text on green backgrounds.

Use:

* White on dark green
* Dark text on mint
* Dark text on white

Accessibility should remain excellent.

# Layout System

## Max Width

1200px

Center aligned.

## Horizontal Padding

Desktop:

80px

Tablet:

48px

Mobile:

24px

## Vertical Spacing

Sections:

96–128px

Between elements:

24–40px

Whitespace is part of the design language.

# Grid System

Use a consistent responsive grid.

Common layouts:

* 2-column
* 3-column
* 4-column card grids

Cards should align perfectly with equal heights.

---

# Border Radius

Large rounded corners.

Buttons:

16px

Cards:

24px

Inputs:

9999px (pill style)

Image containers:

24–32px

Avoid sharp corners.

---

# Shadows

Soft and subtle.

Example:

0 10px 30px rgba(0,0,0,0.06)

Avoid heavy drop shadows.

Use elevation sparingly.

# Icon Style

Use simple outline or rounded icons.

Preferred:

* Lucide
* Heroicons
* Phosphor

Icons should be:

* Consistent stroke width
* Green accented
* Minimal

Avoid overly detailed illustrations unless I provide references.

---

# Illustration Style

I will provide reference images.

When illustrations are needed:

Use clean **3D-style rendered objects** similar to ScrapUncle.

Examples:

* Weighing scale
* Metal scrap
* Batteries
* Appliances
* Trucks
* Recycling containers
* Warehouses

Keep illustrations bright and polished.

---

# Image Treatment

Use:

* Rounded corners
* Soft shadows
* Clean backgrounds

Avoid:

* Harsh industrial photos
* Dirty scrap-yard imagery
* Overly dramatic HDR effects

The website should feel **organized**, even if the business deals with scrap.

# Animations

Use subtle motion only.

Allowed:

* Fade in
* Slide up
* Scale on hover
* Button hover
* Card lift
* Icon rotation (minimal)

Duration:

200–350ms

Easing:

ease-out

Avoid:

* Bounce animations
* Parallax overload
* Continuous motion
* Excessive scroll effects

---

# Forms

Keep forms minimal.

Inputs:

* Rounded
* Large
* Comfortable touch targets

Use:

* Name
* Phone
* Material type
* Quantity
* Pickup location

Primary CTA:

**Request Pickup**

---

# Mobile Design

Mobile is the highest priority.

Requirements:

* Thumb-friendly buttons
* Sticky WhatsApp button
* Sticky call button (optional)
* Large spacing
* Readable typography
* Fast loading
* Minimal scrolling friction

Navigation should collapse cleanly.

---

# Component Rules

Every component should follow these principles:

* Rounded
* Spacious
* Consistent
* Accessible
* Reusable

No inconsistent padding.

No random colors.

No decorative clutter.

---

# What to Avoid

Do not create:

* AI startup gradients
* Glassmorphism everywhere
* Neon effects
* Cyberpunk themes
* Heavy industrial textures
* Rusty metal backgrounds
* Overly dark layouts
* Stock-template aesthetics
* Generic recycling icons repeated everywhere

---

# Visual Benchmark

The final website should look like a **high-quality, professionally designed recycling platform** comparable to ScrapUncle in polish, but clearly branded as **ZeroSkrap, Mauritius**.

If a design decision is uncertain, choose the option that is:

* cleaner,
* simpler,
* more trustworthy,
* more spacious,
* and more conversion-focused.
